# Claude Writing Workflow - Quick Reference

## The 10 Prompts (In Order)

1. **5-Minute First Draft** - Get ideas down fast
2. **Research Synthesizer** - Organize sources and findings
3. **Clarity Surgeon** - Simplify complex sections
4. **Hook Generator** - Create compelling headlines
5. **Citation Weaver** - Integrate sources naturally
6. **Flow Fixer** - Improve transitions
7. **Tone Adjuster** - Match audience and platform
8. **Story Structure Overlay** - Add narrative elements
9. **Simplicity Test** - Explain complex topics clearly
10. **Final Polish** - Catch errors before publishing

## Quick Workflow

**Planning** → Research Synthesizer + 5-Minute First Draft
**Refinement** → Clarity Surgeon + Flow Fixer + Simplicity Test
**Enhancement** → Hook Generator + Citation Weaver + Tone Adjuster + Story Structure
**Finalization** → Final Polish

## Usage

To use this skill, simply say:
- "Use the claude-writing-workflow skill to write an article about [topic]"
- "Apply the Clarity Surgeon prompt to this section"
- "Generate hooks for my article using the Hook Generator"

See `SKILL.md` for complete prompt templates and detailed instructions.
