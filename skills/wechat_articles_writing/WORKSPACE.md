# 公众号写作工作流 · WORKSPACE

> 3步生成90分公众号文章 | 无需培训 | 80-110分钟完成

---

## 🎯 工作流概览

这套工作流帮助小白用户，无需培训，通过3步线性流程，配合AI交互式引导，生成高质量公众号文章。

**核心特点**：
- ✅ 简单：只需3步，每步都有AI引导
- ✅ 快速：80-110分钟完成一篇2000-2500字文章
- ✅ 高质：双视角评估，确保文章达到90-95分
- ✅ 省心：自动保存，带格式复制，直接发布

---

## 📋 工作流程图

```
开箱设置（首次使用）
    ↓
┌─────────────────────────────┐
│  第一步：选题（15-20分钟）    │
│  - 想法归类                  │
│  - 扩展选题（AI生成10个）     │
│  - 筛选优化（用户选1个）      │
│  → 输出：选题确认单          │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│  第二步：写作（45-60分钟）    │
│  - AI根据KY模板生成初稿      │
│  - 用户确认是否满意          │
│  → 输出：2000-2500字初稿     │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│  第三步：优化（20-30分钟）    │
│  - AI生成双视角评估报告      │
│  - 用户选择改进建议          │
│  - AI优化并生成MD文件        │
│  → 输出：90-95分成品文章     │
└─────────────────────────────┘
    ↓
发布到公众号
```

## 🚀 使用指南

### 前提条件：打开工作流程

在文件夹上右键，选择 “在终端中打开”

输入 Claude

等待 Claude Code 启动完成。

---

## 📦 首次开箱设置（仅第一次需要）

### 启动开箱设置

**对 Claude 说：**

```
我是第一次使用，请帮我完成开箱设置
```

---

### 回答4个问题

Claude 会依次问你4个问题，直接回答即可：

**问题1：目标用户是谁？**

示例回答：
- `30-45岁职场女性`
- `25-35岁新手妈妈`
- `18-25岁大学生`

**问题2：内容领域是什么？**

示例回答：
- `家庭关系、夫妻沟通、亲子教育`
- `职场成长、时间管理、个人发展`
- `阅读写作、知识管理、终身学习`

**问题3：你的身份/背景是什么？**

示例回答：
- `心理咨询师，10年从业经验`
- `小学教师，关注儿童教育`
- `资深读书人，年阅读量100+本`

**问题4：文章风格偏好？**

示例回答：
- `专业解析，深度有料`
- `故事分享，真实温暖`

---

### 完成开箱设置

Claude 会保存你的档案，并提示：

```
✅ 开箱设置完成！
现在对我说："我要写一篇公众号文章"，开始你的第一篇文章创作。
```

---

## 第一步：选题（15-20分钟）

### 1.1 启动选题

**对 Claude 说：**

```
我要写一篇公众号文章
```

---

### 1.2 想法归类

Claude 会问：

```
你想写关于什么主题的文章？
```

**示例回答**：
- `我想写关于夫妻沟通的文章`
- `我想写关于职场时间管理的文章`
- `我想写关于阅读方法的文章`

---

### 1.3 扩展选题

Claude 会继续问：

```
我现在帮你生成10个爆款选题。请告诉我：

1. 选题字数要求？（建议15-25字）
2. 是否需要结合最近时事热点？
3. 是否有特定的冲突点或痛点？
4. 有没有想避开的选题角度？
```

**你只需回答这些问题**，Claude 会为你生成10个选题。

---

### 1.4 筛选优化

Claude 会展示10个选题，并问：

```
请从这10个选题中，选择1-2个你最有感觉的。

哪个选题：
- 让你最想点开看？
- 你最有话可说？
- 最符合你的目标用户？
```

**你选择后**，Claude 会帮你确认：
- 这个选题的核心观点
- 目标读者是谁
- 文章要解决什么问题

---

### 1.5 输出选题确认单

Claude 会自动生成选题确认单，并保存到 `01-选题/选题记录/` 目录：

```markdown
# 选题确认单

**日期**：2026-01-04
**选题**：我采访了20对二胎家庭，发现沟通好的夫妻都做对了这3件事
**核心观点**：二胎后夫妻沟通好的秘诀是做对3件事
**目标读者**：二胎家庭的父母，尤其是妈妈
**要解决的问题**：二胎后夫妻沟通困难，关系疏远

---

准备进入写作阶段
```

---

## 第二步：写作（45-60分钟）

### 2.1 确认进入写作

选题确认后，**对 Claude 说：**

```
选题确认，开始写作
```

---

### 2.2 AI生成初稿

Claude 会基于你的档案和选题，自动：
1. 根据你的内容领域，匹配对应的专业视角
   - 家庭关系 → 心理学/教练视角
   - 教育育儿 → 教育学/发展心理学视角
   - 职场成长 → 管理学/组织行为学视角
   - 阅读写作 → 认知科学/个人成长视角

2. 按照KY四段式结构生成：
   - 第一段：场景化开篇（300-400字）
   - 第二段：专业解析（600-800字）
   - 第三段：方法论（700-900字）
   - 第四段：收尾+互动（200-300字）

3. 一次性生成完整的2000-2500字初稿

---

### 2.3 用户确认初稿

Claude 生成初稿后，会展示全文，并问：

```
初稿已完成（2300字）。

请查看文章，您对初稿满意吗？

如果满意，对我说："满意，进入优化"
如果不满意，告诉我哪里需要调整。
```

---

### 2.4 调整初稿（如需要）

如果不满意，可以要求调整：

**调整开篇**：
```
开篇的案例不太合适，能换成[XX场景]吗？
```

**调整专业解析**：
```
专业解析部分太学术了，能用更生活化的语言吗？
```

**调整方法**：
```
方法2不够具体，能给出更详细的步骤吗？
```

Claude 会根据你的反馈调整，直到你满意。

---

### 2.5 保存初稿

初稿确认后，自动保存到 `02-写作/初稿存档/` 目录：

```
02-写作/初稿存档/20260104-文章标题-初稿.md
```

---

## 第三步：优化（20-30分钟）

### 3.1 生成评估报告

**对 Claude 说：**

```
满意，进入优化
```

Claude 会自动生成双视角评估报告（在一页显示）：

```markdown
📊 文章质量评估报告

【当前文章评分】初稿得分：75分 / 100分

---

👤 读者视角评估（目标用户：30-45岁已婚妈妈）

✨ 亮点（需保留）：
1. 开篇《小舍得》的案例很真实，容易引起共鸣
2. "心理契约"的解释很生活化，容易理解
3. "家庭责任认领会"的方法很具体，可操作性强

⚠️ 改进建议：
1. 专业解析部分可以增加1个小案例，让理论更易懂
2. 方法2的步骤可以更详细，比如具体的时间分配示例
3. 结尾的互动话题可以更具体，比如"你家的家务分工是怎样的？"

---

🎯 批评者视角评估（自媒体营销专家）

✨ 亮点（需保留）：
1. 四段式结构完整，逻辑清晰
2. 专业理论引用恰当，有学术背景支撑
3. 方法论部分提供了3个具体方法，覆盖全面

⚠️ 改进建议：
1. 标题可以更吸引人，建议加上数字或悬念
2. 方法3的"我感受"句式，可以补充更多对比示例
3. 结尾可以增加一句行动召唤，比如"今晚就试试第一个方法"

---

📈 优化后预估分数：90-95分

请告诉我您要采纳哪些改进建议（如："采纳读者1、2、批评者1、3"）
```

---

### 3.2 选择改进建议

你可以：

**全部采纳**：
```
全部采纳
```

**部分采纳**：
```
采纳读者1、2、批评者1、3
```

**自定义改进**：
```
我想改进XX部分，能帮我调整吗？
```

---

### 3.3 AI优化文章

Claude 会根据你选择的建议，优化文章：
- 保留亮点部分
- 优化改进部分
- 展示优化后的文章

---

### 3.4 确认发布

优化版展示后，Claude 会问：

```
优化版已完成。

请查看文章，您满意吗？

如果满意，对我说："满意，生成MD文件"
如果还需要调整，告诉我具体要求。
```

---

### 3.5 生成MD文件

确认满意后，**对 Claude 说：**

```
满意，生成MD文件
```

Claude 会：
1. 生成带格式的MD文件
2. 保存到 `04-成品文章/` 目录
3. 文件名：`20260104-文章标题.md`

并提示：

```
✅ 成品文章已保存！

文件位置：04-成品文章/20260104-文章标题.md

这个文件可以直接复制粘贴到公众号后台发布。
```

## 📄 发布到公众号

### 步骤1：打开成品文章

找到 `04-成品文章/` 目录下的文章文件，打开。

---

### 步骤2：复制文章内容

- 全选复制（Ctrl+A，Ctrl+C）

---

### 步骤3：粘贴到公众号后台

1. 登录微信公众号后台
2. 新建图文消息
3. 直接粘贴（Ctrl+V）

**格式会自动转换，无需手动调整。**

---

### 步骤4：预览和发布

- 点击"预览"，查看手机效果
- 确认无误后，点击"保存并群发"

## ✅ 文章质量标准

每篇文章都会达到：

| 标准 | 要求 |
|------|------|
| **字数** | 2000-2500字（含标点符号） |
| **结构** | 四段式完整（开篇-解析-方法-互动） |
| **专业度** | 根据领域匹配专业视角，有理论支撑 |
| **方法论** | 2-3个具体可操作的方法 |
| **案例** | 真实接地气，易引起共鸣 |
| **互动** | 设置讨论话题，征集读者故事 |
| **评分** | 双视角评估90-95分 |
