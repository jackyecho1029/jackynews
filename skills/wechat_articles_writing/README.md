# 公众号写作工作流

> 小白用户专用 | 3步生成90分公众号文章 | 无需培训 | 80-110分钟完成

---

## 📌 项目简介

这是一套为小白用户设计的公众号写作工作流程，通过AI交互式引导，让零经验的用户也能快速创作出高质量的公众号文章。

**核心价值**：
- ✅ **简单**：只需3步，每步都有AI引导，不需要任何写作经验
- ✅ **快速**：80-110分钟完成一篇2000-2500字的专业文章
- ✅ **高质**：双视角评估，确保文章达到90-95分
- ✅ **省心**：自动保存，带格式复制，可直接发布到公众号

---

## 🚀 快速开始（3步）

### 1️⃣ 打开工作流程

在文件夹上右键，选择 “在终端中打开”

输入 Claude

等待 Claude Code 启动完成。

---

### 2️⃣ 首次使用（仅第一次需要）

对 Claude 说：

```
我是第一次使用，请帮我完成开箱设置
```

回答4个问题（5分钟）：
1. 目标用户是谁？
2. 内容领域是什么？
3. 你的身份/背景是什么？
4. 文章风格偏好？

---

### 3️⃣ 开始写文章

对 Claude 说：

```
我要写一篇公众号文章
```

Claude 会自动引导你完成：
- **第一步：选题**（15-20分钟）→ AI生成10个选题，你选1个
- **第二步：写作**（45-60分钟）→ AI一次性生成2000-2500字初稿
- **第三步：优化**（20-30分钟）→ AI评估+优化，生成90-95分成品

✅ 完成！最终文章保存到 `04-成品文章/` 目录，可直接复制发布。

## 💡 核心特点

### 1. 专业视角自适应

根据你的内容领域，自动匹配专业视角：
- 家庭关系 → 心理学/教练视角
- 教育育儿 → 教育学/发展心理学
- 职场成长 → 管理学/组织行为学
- 阅读写作 → 认知科学/个人成长
- 心理健康 → 临床心理学/积极心理学

---

### 2. KY风格四段式结构

借鉴 KnowYourself 公众号的成功经验：
- 专业但不学术
- 深度但易读
- 提供具体方法

**四段式结构**：
1. 场景化开篇（300-400字）
2. 专业解析（600-800字）
3. 方法论（700-900字）
4. 收尾+互动（200-300字）

---

### 3. 双视角评估系统

两个角度全面评估：
- **读者视角**：代入感、行动转化、传播意愿
- **批评者视角**：论证严谨、方法可执行、发布风险

每个视角3条亮点 + 3条改进建议 = 全面优化

---

### 4. 自动化文件管理

所有文件自动保存，按日期归档：
- 选题记录 → `01-选题/选题记录/`
- 初稿存档 → `02-写作/初稿存档/`
- 评估报告 → `03-优化/评估记录/`
- 成品文章 → `04-成品文章/`

## 🆘 常见问题

### Q1: 我没有任何写作经验，能用吗？

**可以！**这套工作流就是为小白用户设计的。只要会打字，会和Claude对话，就能使用。

---

### Q2: 我不懂专业理论，怎么办？

**不需要懂！**AI会根据你的领域，自动匹配专业视角和理论，并用生活化语言解释。

---

### Q3: 生成的文章质量如何？

**90-95分！**经过双视角评估和优化，每篇文章都达到专业标准：
- 结构完整
- 有专业理论支撑
- 方法具体可操作
- 案例真实接地气

---

### Q4: 我能自定义风格吗？

**可以！**在写作过程中，你可以随时要求调整：
- 更换开篇案例
- 调整专业理论
- 优化方法步骤
- 改进互动话题

---

### Q5: 生成的文章能直接发布吗？

**可以！**生成的MD文件带格式，直接复制粘贴到公众号后台即可，无需手动调整格式。
