# 目录结构说明

> 理解每个目录的作用，让你更高效地使用工作流

---

## 📁 完整目录结构

```
公众号写作/
├── 00-快速开始/
│   ├── 使用说明.md          ← 小白用户快速入门
│   ├── 首次开箱设置.md       ← 4个问题详细说明
│   └── 目录结构说明.md       ← 你正在看的这个文件
│
├── 01-选题/
│   ├── 选题工作流程.md       ← 李一舟3步选题法详细说明
│   └── 选题记录/            ← 自动保存每次选题的记录
│       └── YYYYMMDD-选题记录.md
│
├── 02-写作/
│   ├── KY写作模板.md        ← 四段式结构 + 各领域专业视角
│   ├── KY风格生成提示词.md  ← AI生成初稿的完整提示词
│   └── 初稿存档/            ← 自动保存每篇文章的初稿
│       └── YYYYMMDD-文章标题-初稿.md
│
├── 03-优化/
│   ├── 评估优化指南.md       ← 双视角评估系统使用说明
│   └── 评估记录/            ← 自动保存每次评估报告
│       └── YYYYMMDD-文章标题-评估报告.md
│
├── 04-成品文章/             ← 最终发布的文章（可直接复制发布）
│   └── YYYYMMDD-文章标题.md
│
├── WORKSPACE.md             ← 完整工作流程主文件
└── README.md                ← 项目说明和快速索引
```

---

## 📂 各目录详细说明

### 00-快速开始/

**作用**：新手入门资料，帮助小白用户快速上手

**包含文件**：
- `使用说明.md` - 3步快速开始指南
- `首次开箱设置.md` - 4个开箱问题的详细说明
- `目录结构说明.md` - 完整目录结构解释

**使用场景**：
- 第一次使用时，先看`使用说明.md`
- 不确定怎么回答开箱问题时，看`首次开箱设置.md`
- 想了解整个系统结构时，看`目录结构说明.md`

---

### 01-选题/

**作用**：选题阶段的工具和记录

**包含文件**：
- `选题工作流程.md` - 李一舟3步选题法（想法归类 → 扩展选题 → 筛选优化）
- `选题记录/` - 每次选题的详细记录（自动保存）

**使用场景**：
- 不知道写什么时，打开`选题工作流程.md`学习方法
- 想回顾之前的选题，查看`选题记录/`目录

**文件命名规则**：
```
选题记录/20260104-家庭关系选题记录.md
```

---

### 02-写作/

**作用**：写作阶段的模板、提示词和初稿存档

**包含文件**：
- `KY写作模板.md` - 四段式结构详细说明 + 各领域专业视角示例
- `KY风格生成提示词.md` - AI生成初稿的完整提示词（可复制使用）
- `初稿存档/` - 每篇文章的初稿（自动保存）

**使用场景**：
- 想了解四段式结构，打开`KY写作模板.md`
- 想自己调整生成效果，查看`KY风格生成提示词.md`
- 想对比初稿和优化版，查看`初稿存档/`

**文件命名规则**：
```
初稿存档/20260104-如何改善夫妻沟通-初稿.md
```

---

### 03-优化/

**作用**：优化评估阶段的指南和评估记录

**包含文件**：
- `评估优化指南.md` - 双视角评估系统详细说明
- `评估记录/` - 每次评估的完整报告（自动保存）

**使用场景**：
- 不理解评估报告怎么看，打开`评估优化指南.md`
- 想回顾某篇文章的评估，查看`评估记录/`

**文件命名规则**：
```
评估记录/20260104-如何改善夫妻沟通-评估报告.md
```

---

### 04-成品文章/

**作用**：存放最终优化后的文章，可直接发布

**包含文件**：
- 所有优化完成、可直接发布的MD文件

**使用场景**：
- 打开这个目录，找到你要发布的文章
- 复制MD文件内容，粘贴到公众号后台

**文件命名规则**：
```
04-成品文章/20260104-如何改善夫妻沟通.md
```

**重要提示**：
- ✅ 这个目录的文章都是**带格式**的
- ✅ 可以**直接复制粘贴**到公众号后台
- ✅ 不需要再做任何格式调整

## 🗂️ 文件自动保存规则

**所有自动生成的文件都遵循统一命名规则**：

```
YYYYMMDD-文件描述.md
```

**示例**：
- `20260104-选题记录.md`
- `20260104-如何改善夫妻沟通-初稿.md`
- `20260104-如何改善夫妻沟通-评估报告.md`
- `20260104-如何改善夫妻沟通.md`（成品）

**好处**：
- ✅ 按日期排序，清晰直观
- ✅ 文件名就能看出内容
- ✅ 方便查找和管理
