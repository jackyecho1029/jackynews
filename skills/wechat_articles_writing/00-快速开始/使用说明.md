# 📱 公众号写作工作流 · 使用说明

> 3步生成90分公众号文章 | 无需培训 | 80-110分钟完成

---

## 🚀 快速开始（3步）

### 1️⃣ 打开工作流程

在文件夹上右键，选择 “在终端中打开”

输入 Claude

等待 Claude Code 启动完成。

---

### 2️⃣ 首次使用（仅第一次需要）

**对 Claude 说：**

```
我是第一次使用，请帮我完成开箱设置
```

Claude 会问你4个问题：
1. 目标用户是谁？
2. 内容领域是什么？
3. 你的身份/背景是什么？
4. 文章风格偏好？

**回答这4个问题即可**，Claude 会保存你的档案。

---

### 3️⃣ 开始写文章（3步走）

**对 Claude 说：**

```
我要写一篇公众号文章
```

Claude 会自动引导你完成：

**第一步：选题（15-20分钟）**
- Claude 帮你生成10个选题
- 你选择1-2个最喜欢的
- 确认核心观点

**第二步：写作（45-60分钟）**
- Claude 根据你的档案，一次性生成2000-2500字初稿
- 你确认是否满意
- 不满意可以要求调整

**第三步：优化（20-30分钟）**
- Claude 生成评估报告（两个视角，一页显示）
- 你选择要采纳的改进建议
- Claude 修改并生成最终版MD文件

**✅ 完成！**

最终MD文件会保存到 `04-成品文章/` 目录下，打开MD文件，可直接复制粘贴到公众号后台发布。

## ⏱️ 时间预估

- **选题**：15-20分钟
- **写作**：45-60分钟
- **优化**：20-30分钟
- **总计**：80-110分钟

---

## ✅ 文章标准

每篇文章都会达到：
- ✅ 2000-2500字
- ✅ 四段式结构（开篇-解析-方法-互动）
- ✅ 专业视角分析（根据你的领域自动匹配）
- ✅ 2-3个可操作方法
- ✅ 评估分数90-95分
