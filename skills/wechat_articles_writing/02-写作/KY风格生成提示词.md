# KY风格生成提示词

> 复制这个提示词，让AI帮你生成符合KY风格的2000-2500字文章

---

## 📋 完整提示词（可直接复制）

```markdown
请根据以下信息，用KY风格生成一篇2000-2500字的公众号文章。

## 用户档案
**目标用户**：[从开箱设置获取]
**内容领域**：[从开箱设置获取]
**身份背景**：[从开箱设置获取]
**风格偏好**：专业解析，深度但易读，提供方法

## 选题信息
**文章标题**：[从选题确认单获取]
**核心观点**：[从选题确认单获取]
**目标读者**：[从选题确认单获取]
**要解决的问题**：[从选题确认单获取]

## 写作要求

### 整体风格：KY风格
- 专业但不学术
- 深度但易读
- 提供具体方法

### 字数要求
- 总字数：2000-2500字（含标点符号）
- 第一段：300-400字（场景化开篇）
- 第二段：600-800字（专业解析）
- 第三段：700-900字（方法论）
- 第四段：200-300字（收尾+互动）

### 四段式结构

**第一段：场景化开篇（300-400字）**

要求：
1. 用影视剧或真实故事引入（200-250字）
   - 具体的场景和对话
   - 展现冲突
   - 选择目标读者熟悉的影视剧

2. 共鸣点植入（50-100字）
   - "你是否也有过类似的时刻？"
   - 说明普遍性

3. 问题引出（50字）
   - "这背后到底是什么原因？"
   - 过渡到下一段

示例开头：
```
《小舍得》里有这样一幕：

田雨岚下班回家，发现老公颜鹏在客厅玩手机，儿子子悠的作业还没检查。她忍不住说了句："你就不能盯着孩子写作业吗？"

颜鹏头也不抬："我工作了一天，不能休息会儿？"

田雨岚瞬间爆发："休息？我也工作了一天！凭什么我下班还要管孩子，你就可以玩手机？"

这一幕，在多少家庭中上演过？

在我们社群里，70%的妈妈都说过类似的话...
```

---

**第二段：专业解析（600-800字）**

要求：
1. 提出核心观点（100字）
   - "这种冲突的本质是XX"

2. 专业理论解释（300-400字）
   - 根据用户的内容领域，自动匹配专业视角：
     * 家庭关系 → 心理学/教练视角（依恋理论、心理契约、沟通模式）
     * 教育育儿 → 教育学/发展心理学（认知发展、学习动机、教育心理学）
     * 职场成长 → 管理学/组织行为学（时间管理、目标管理、领导力理论）
     * 阅读写作 → 认知科学/个人成长（知识管理、深度工作、刻意练习）
     * 心理健康 → 临床心理学/积极心理学（情绪调节、认知重构、正念疗法）
   - 引入1个核心理论
   - 用生活化语言解释，不要学术化
   - 多用"换句话说""简单讲"

3. 多维度分析（300-400字）
   - 从2-3个角度分析
   - 每个角度都有小标题
   - 配合小案例说明

4. 小结（100字）
   - 总结核心洞察
   - 过渡到方法论

**重点**：
- 只用1-2个理论，不要贪多
- 理论解释控制在200字以内
- 避免专业术语堆砌

---

**第三段：方法论（700-900字）**

要求：
1. 提供2-3个具体可操作的方法
2. 每个方法250-300字，包含：
   - 方法名称（小标题）
   - 为什么有效（50-100字）
   - 具体步骤（150-200字）- 必须是可执行的步骤
   - 真实案例（50-80字）
   - 注意事项（20-50字）

方法编号格式：
```
### 方法1: [方法名称]

[为什么有效]

**具体步骤：**
1. [步骤1]
2. [步骤2]
3. [步骤3]

**真实案例：**
[案例描述]

**注意事项：**
[注意事项]
```

**重点**：
- 方法必须具体可操作
- 步骤要清晰明确
- 案例要真实接地气

---

**第四段：收尾+互动（200-300字）**

要求：
1. 金句收尾（100-150字）
   - 升华主题
   - 温暖有力量
   - 给读者希望

2. 今日互动（100-150字）
   - 1-2个讨论话题
   - 征集读者故事
   - 建立社群感

示例：
```
家庭关系不是天生就和谐的，需要我们持续地沟通、调整、磨合。

那些看起来岁月静好的夫妻，不是因为他们从不争吵，而是因为他们懂得在冲突中看见彼此，在平淡中彼此负责。

愿你们都能成为这样的夫妻。

---

**今日互动**

在你的家庭里，是否也有类似的"隐形期待"冲突？
你们是如何解决的？
欢迎在评论区分享你的故事～

我会精选3-5个故事，在下期文章中和大家一起讨论。
```

---

### 语言风格要求

1. **专业但不学术**
   - ❌ "根据依恋理论中的回避型依恋模式，个体在亲密关系中会表现出情感疏离的防御机制..."
   - ✅ "有些人在关系里总是若即若离，心理学把这种模式叫做'回避型依恋'。简单说，就是越亲近越想逃..."

2. **深度但易读**
   - 用短句
   - 多用具体例子
   - 避免长篇大论

3. **真实接地气**
   - 用真实的场景和对话
   - 避免假大空的案例
   - 语言口语化

### 检查清单

生成文章后，请自检：

**结构检查**：
- [ ] 总字数2000-2500字？
- [ ] 四段式结构完整？
- [ ] 每段字数比例合理？

**专业度检查**：
- [ ] 引用了1-2个专业理论？
- [ ] 理论解释生活化、易懂？
- [ ] 根据用户领域匹配了专业视角？

**可操作性检查**：
- [ ] 方法具体可执行？
- [ ] 有清晰的步骤？
- [ ] 有真实案例支撑？

**可读性检查**：
- [ ] 有小标题分段？
- [ ] 避免过长段落？
- [ ] 语言口语化？

**互动性检查**：
- [ ] 设置了互动话题？
- [ ] 征集了读者故事？
```

## 🔧 如何使用这个提示词

### 步骤1：复制提示词

复制上面"完整提示词"部分的全部内容。

---

### 步骤2：填入你的信息

在Claude中粘贴提示词，并填入以下信息：

**用户档案部分**：
- 从你的开箱设置中获取

**选题信息部分**：
- 从选题确认单中获取

**示例**：

```markdown
## 用户档案
**目标用户**：30-45岁已婚妈妈
**内容领域**：家庭关系、夫妻沟通、亲子教育
**身份背景**：心理咨询师 + 认证教练，11岁女孩的妈妈
**风格偏好**：专业解析，深度但易读，提供方法

## 选题信息
**文章标题**：我采访了20对二胎家庭，发现沟通好的夫妻都做对了这3件事
**核心观点**：二胎后夫妻沟通好的秘诀是做对3件事
**目标读者**：二胎家庭的父母，尤其是妈妈
**要解决的问题**：二胎后夫妻沟通困难，关系疏远
```

---

### 步骤3：生成文章

发送给Claude，等待生成。

Claude会自动：
- 根据你的领域匹配专业视角
- 生成符合KY风格的四段式文章
- 控制字数在2000-2500字

---

### 步骤4：确认和调整

如果生成的文章不满意，可以：

**调整开篇**：
```
开篇的影视剧案例不太合适，能换成[XX影视剧]的场景吗？
```

**调整专业理论**：
```
专业解析部分太学术了，能用更生活化的语言解释吗？
```

**调整方法**：
```
方法2不够具体，能给出更详细的步骤吗？
```

---

## 💡 常见调整需求

### 调整1：更换开篇案例

**对Claude说：**
```
开篇用《小舍得》的案例不太合适我的读者，
能换成关于[XX场景]的真实故事吗？
```

---

### 调整2：增加方法的可操作性

**对Claude说：**
```
方法1的步骤还不够具体，
能把每个步骤展开，给出更详细的操作说明吗？
```

---

### 调整3：调整专业理论

**对Claude说：**
```
专业解析部分用的[XX理论]对我的读者来说太陌生，
能换成[YY理论]吗？
```

---

### 调整4：增加案例

**对Claude说：**
```
能在专业解析部分增加1-2个真实案例吗？
让读者更容易理解。
```

### 问题1：生成的文章太短

**对Claude说：**
```
文章只有1500字，不够2000字。
请在[专业解析/方法论]部分补充内容。
```

---

### 问题2：生成的文章太长

**对Claude说：**
```
文章超过3000字了，太长。
请精简到2000-2500字，保留核心内容。
```

---

### 问题3：方法不够具体

**对Claude说：**
```
方法太空泛，不知道怎么做。
请给出更具体的、可执行的步骤。
```

---

### 问题4：专业理论太学术

**对Claude说：**
```
专业解析部分太学术，读者看不懂。
请用更生活化的语言重新解释。
```
