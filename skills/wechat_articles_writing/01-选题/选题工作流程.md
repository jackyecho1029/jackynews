# 选题工作流程（选题3步法）

> 从想法到爆款选题，只需3步，15-20分钟搞定

---

## 为什么需要选题？

好的选题是文章成功的一半：
- ✅ 吸引目标读者点击
- ✅ 确定文章核心观点
- ✅ 让写作有清晰方向

**没有好选题，再好的文笔也白费。**

---

## 3步选题法

### 步骤1：想法归类（5分钟）

**目标**：确定这次写作的核心领域

**操作**：

**对 Claude 说：**
```
我想写关于 [具体领域] 的文章
```

**示例**：
- `我想写关于夫妻沟通的文章`
- `我想写关于职场时间管理的文章`
- `我想写关于阅读方法的文章`
- `我想写关于儿童教育的文章`

**Claude 会做什么**：
- 确认你的内容领域
- 了解你想聚焦的具体方向
- 为下一步扩展选题做准备

---

### 步骤2：扩展选题（10分钟）

**目标**：生成10个潜在爆款选题

**操作**：

**Claude 会问你**：

```
我现在帮你生成10个爆款选题。请告诉我：

1. 选题字数要求？（建议15-25字）
2. 是否需要结合最近时事热点？
3. 是否有特定的冲突点或痛点？
4. 有没有想避开的选题角度？
```

**你只需回答这些问题**，Claude 会为你生成10个选题。

**示例生成的选题**：

假设你的领域是"夫妻沟通"，Claude 可能生成：

```
1. 为什么有些夫妻越沟通越疏远？心理学给出了答案
2. 我采访了20对二胎家庭，发现沟通好的夫妻都做对了这3件事
3. 结婚5年依然甜蜜的夫妻，都有这个共同点——
4. 夫妻沟通的最大杀手，不是冷战而是...
5. 为什么老公总说"我知道了"却不改？问题出在这
6. 二胎后依然恩爱的夫妻，都懂得这个沟通技巧——
7. 那些让夫妻关系越来越好的对话，都有这3个特点
8. 你和伴侣是"假性沟通"吗？3个信号帮你判断
9. 夫妻吵架后的黄金修复期，90%的人都错过了
10. 为什么有些话说出口就后悔？心理学教你3个沟通原则
```

---

### 步骤3：筛选优化（5分钟）

**目标**：从10个选题中选出最好的1-2个

**操作**：

**Claude 会问你**：

```
请从这10个选题中，选择1-2个你最有感觉的。

哪个选题：
- 让你最想点开看？
- 你最有话可说？
- 最符合你的目标用户？
```

**你选择后**，Claude 会帮你：
- 确认这个选题的核心观点
- 确认目标读者是谁
- 确认文章要解决什么问题

**示例对话**：

```
你：我选择第2个和第6个

Claude：好的，这两个都不错。我们来对比一下：

第2个："我采访了20对二胎家庭，发现沟通好的夫妻都做对了这3件事"
- 优势：真实感强，数字明确，有方法论承诺
- 适合：需要具体方法的读者

第6个："二胎后依然恩爱的夫妻，都懂得这个沟通技巧——"
- 优势：悬念感强，场景具体，有共鸣
- 适合：二胎家庭，关注夫妻关系

你更倾向于哪一个？或者想结合两者的优势？

你：我选第2个

Claude：很好！这个选题的核心观点是：
"二胎后夫妻沟通好的秘诀是做对3件事"

目标读者：二胎家庭的父母，尤其是妈妈

文章要解决的问题：二胎后夫妻沟通困难，关系疏远

我们开始写作吧！
```

## 选题确认单（自动生成）

完成3步后，Claude 会自动生成一份选题确认单：

```markdown
# 选题确认单

**日期**：2026-01-04
**选题**：我采访了20对二胎家庭，发现沟通好的夫妻都做对了这3件事
**核心观点**：二胎后夫妻沟通好的秘诀是做对3件事
**目标读者**：二胎家庭的父母，尤其是妈妈
**要解决的问题**：二胎后夫妻沟通困难，关系疏远
**文章角度**：方法论输出，提供3个具体可操作的方法

---

准备进入写作阶段
```

这份确认单会自动保存到 `01-选题/选题记录/` 目录。

## 常见问题

### Q1: 我完全没有想法怎么办？

**对 Claude 说：**
```
我不知道写什么，请帮我推荐一些选题
```

Claude 会根据你的用户档案（领域、目标用户），推荐热门选题方向。

---

### Q2: 我有多个想法，能同时生成吗？

可以！对 Claude 说：
```
我有3个想法：
1. 夫妻沟通
2. 亲子教育
3. 时间管理

请分别为这3个方向各生成5个选题
```

---

### Q3: 生成的选题都不太满意怎么办？

**对 Claude 说：**
```
我对这10个选题都不太满意，能不能：
1. 更聚焦 [具体角度]
2. 更强调 [具体特点]
3. 避开 [不想要的角度]

再生成10个
```

---

### Q4: 我想结合最近的热点，怎么做？

**对 Claude 说：**
```
最近 [某热点事件] 很火，能帮我结合这个热点，
生成10个关于 [我的领域] 的选题吗？
```

示例：
```
最近教育部发布了"双减"政策，能帮我结合这个热点，
生成10个关于家庭教育的选题吗？
```

---

## 选题质量自检

好的选题应该满足：

**5个标准**：
- [ ] 长度合适（15-25字）
- [ ] 有吸引力（让人想点开）
- [ ] 有具体性（不空泛）
- [ ] 有悬念感（制造好奇）
- [ ] 符合目标用户（他们关心的话题）

**3个避免**：
- ❌ 太宽泛（如："如何提升沟通能力"）
- ❌ 太学术（如："基于依恋理论的婚姻沟通研究"）
- ❌ 太平淡（如："夫妻沟通的重要性"）
